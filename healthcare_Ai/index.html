System Architecture

Frontend (Patient & Doctor Portals)

Responsive, dynamic interface built for speed and security. Handles localized state for symptom wizards and real-time appointment booking.

API Gateway & Security Layer

Acts as the unified entry point. Fully authenticates JWT tokens, logging securely and handling Role-Based Access Control to enforce privacy.

AI Diagnostic Microservice

Dedicated Python/FastAPI service querying advanced medical Large Language Models. Generates risk factors, maps symptoms to conditions, and searches vector DBs of specialists.

Core Databases (EHR)

Uses a hybrid data structure: PostgreSQL for structured appointments/user mapping, and an encrypted Document Database for the Electronic Health Record storage.
